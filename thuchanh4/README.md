# Thực hành 4 – Ôn tập Bài 07

- **Sinh viên:** Ngô Lê Tấn Nhân
- **MSSV:** N24DCDT059
- **Ngôn ngữ:** Python 3

Thư mục này gồm lời giải các bài từ bài 21 đến bài 53 và ba bài thực hành TH7.1, TH7.2A, TH7.2B của báo cáo Ôn tập Bài 07. Nội dung xoay quanh cây nhị phân tìm kiếm (BST), cây AVL, đống (heap), cây quyết định và thuật toán minimax / alpha-beta.

## Cách chạy

Mỗi bài là một file độc lập, chạy trực tiếp bằng Python:

```bash
python bai21.py
python TH7_1.py
```

Nếu terminal không hiển thị đúng tiếng Việt, thêm tùy chọn `-X utf8`:

```bash
python -X utf8 bai29.py
```
